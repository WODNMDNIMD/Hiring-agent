# Demo 视频预览检查清单

录制完成后，可以按这份清单检查视频是否适合提交。若需要我帮你预览，请把视频文件路径或文件发给我。

## 基本要求

- 视频时长建议 3-5 分钟；
- 开头 15 秒内说明项目名称和解决痛点；
- 全程不要暴露真实 API Key、Webhook、手机号或邮箱；
- 浏览器只保留 Demo 页面，避免无关标签页分散注意力；
- 字幕或讲解词与页面操作保持同步。

## 必须展示的页面

- `岗位配置`：说明 JD 是匹配依据；
- `AI候选人录入`：展示简历解析、匹配点、风险点、推荐语；
- `企业微信群`：说明 Mock/真实 Webhook 模式；
- `面试官反馈`：展示反馈解析和状态更新；
- `候选人台账`：展示自动记录和筛选；
- `招聘看板`：展示漏斗、岗位分布和负责人负载；
- `事件日志`：展示可追溯和集成日志。

## 常见问题

### 页面操作太多

只保留主链路，不要逐个解释所有按钮。重点是“AI 解析 -> HR 确认 -> 自动更新”。

### 讲解太像功能列表

每个页面都要带一句业务价值。例如：

> 这一页替代的是 HR 手工维护招聘台账的工作。

### Mock 模式看起来不真实

需要主动说明：

> Demo 默认使用 Mock 模式，是为了不依赖企业授权；系统已经把企业微信和腾讯文档做成适配器，后续替换真实 API 即可。

### 事件日志太技术

强调它的业务意义：

> 事件日志保证 AI 参与招聘流程后，每一步都有记录，方便审计、排查和回溯。
