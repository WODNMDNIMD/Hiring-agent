# RecruitFlow AI 项目实施计划

## 项目定位

RecruitFlow AI 是一个轻量招聘流程智能助手，重点解决 HR 在简历进入、推荐语生成、面试官反馈跟进、在线文档更新和招聘复盘中的重复录入问题。

本项目不做完整 ATS，不做复杂权限系统，不做招聘平台抓取。MVP 只保留一条可演示、可落地的主链路。

## MVP 主流程

```text
岗位配置
  ↓
简历上传 / 文本粘贴
  ↓
AI解析候选人字段 + JD匹配 + 推荐语
  ↓
HR确认
  ↓
候选人入库 + 企业微信推送 + 腾讯文档Mock同步
  ↓
面试官反馈解析
  ↓
状态机校验 + HR确认
  ↓
台账与看板刷新
```

## 模块拆分

### M1 项目基础

- Streamlit 应用入口；
- SQLite 数据库；
- `.env` 配置；
- README 和 Demo 脚本。

### M2 简历解析与推荐

- PDF / DOCX / TXT 文本抽取；
- 候选人字段结构化；
- JD 匹配点和风险点；
- 标准化推荐语；
- Mock 模式和真实大模型模式。

### M3 招聘流程工作流

- 候选人去重；
- 申请记录创建；
- 招聘状态机；
- 事件日志；
- HR 确认机制。

### M4 面试官反馈解析

- 粘贴群反馈；
- 识别“可以约面 / 不合适 / 进入复试 / 发Offer”等意图；
- 生成邀约话术；
- 更新流程状态。

### M5 企业微信与文档同步

- 企业微信群机器人 Webhook；
- Mock 腾讯文档 CSV；
- 后续替换为腾讯文档 Open API；
- 同步日志。

### M6 数据看板

- 候选人总数；
- 阶段漏斗；
- 岗位候选人分布；
- 平均匹配分；
- 事件与同步记录。

## 后续迭代

1. 接入 DeepSeek / Qwen 真实模型。
2. 增加候选人详情页和事件时间线。
3. 增加面试超时提醒。
4. 接入企业微信自建应用消息回调。
5. 接入腾讯文档真实 API。
6. 增加部署到 Streamlit Cloud / Render 的说明。

## 当前验收标准

- 不配置 API Key 也能运行；
- 可以完成一次简历解析和推荐；
- 可以确认入库；
- 可以解析一次面试官反馈；
- 可以更新候选人状态；
- 可以看到招聘看板和同步日志。
