# RecruitFlow AI 架构说明

## 核心链路

```text
岗位JD
  ↓
简历上传 / 文本粘贴
  ↓
AI解析：候选人字段 + 岗位匹配 + 推荐语
  ↓
HR确认
  ↓
候选人入库 + 推送企业微信群 + 同步腾讯文档Mock
  ↓
面试官反馈粘贴
  ↓
AI识别意图 + 状态机校验
  ↓
HR确认更新
  ↓
招聘台账与看板刷新
```

## 模块划分

- `recruitflow/ai`：简历解析、推荐语生成、面试官反馈解析、Prompt。
- `recruitflow/core`：数据库、数据模型、状态机、工作流编排。
- `recruitflow/integrations`：企业微信、腾讯文档、Mock同步适配器。
- `recruitflow/ui`：预留 UI 组件目录，当前 MVP 入口在 `app.py`。
- `scripts`：初始化数据库、生成演示数据。

## 设计原则

- AI 只负责非结构化信息理解和文本生成。
- 状态流转、去重、入库、同步日志使用确定性代码。
- 默认 Mock 模式，保证无外部授权也能完整演示。
- 企业微信监听和腾讯文档真实 API 放在适配器层，后续替换输入/输出层即可。
