# Demo 演示脚本

## 1. 新建岗位

打开“岗位配置”，确认已有 `AI产品经理` 岗位，JD 中包含 B端、SaaS、AI Agent、数据分析等要求。

## 2. AI候选人录入

进入“AI候选人录入”，使用默认简历文本或上传 `samples/demo_resume.txt`。

点击“AI解析并生成推荐语”，展示：

- 候选人结构化字段；
- 匹配分；
- 匹配点；
- 风险点；
- 标准化推荐语。

点击“确认入库并推送面试官群”，展示候选人进入 `待二审`。

## 3. 处理面试官反馈

进入“面试官反馈”，粘贴：

```text
李明可以约面，建议安排下周二下午，重点考察项目推进能力。
```

点击“AI解析反馈”，展示动作意图、下一状态、邀约话术。

点击“确认更新流程状态”，状态更新为 `初试待安排`。

## 4. 查看台账和看板

进入“候选人台账”和“招聘看板”，展示：

- 候选人记录；
- 招聘阶段漏斗；
- 岗位候选人分布；
- 平均匹配分。

## 5. 查看同步日志

进入“事件与同步日志”，展示：

- 招聘事件日志；
- 腾讯文档 Mock CSV 同步结果。
